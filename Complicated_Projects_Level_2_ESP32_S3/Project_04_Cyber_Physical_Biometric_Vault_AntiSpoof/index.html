Project 4: Cyber-Physical Biometric Access & Anti-Spoofing Vault Controller

Level 2 Sensor Fusion: Liveness Verification & Time-Gate Defense

Conventional biometric access systems (fingerprint, NFC) are easily spoofed with printed latex, gel molds, or stolen RFID cards. This system introduces true **Photoplethysmographic (PPG) Liveness Verification**: an optical blood volume pulse curve is analyzed at 250 Hz in FreeRTOS Core 1. Access requires living capillary blood flow, active capacitive touch presence, valid operational shift hours verified via a hardware **DS1302 Real-Time Clock**, and an undisturbed **6-DOF IMU seismic tamper envelope**.

1. Multi-Core FreeRTOS Task Architecture

  • Core 1 (250 Hz Optical PPG Task): High-resolution sampling of Module #17 pulse rate monitor. Applies dynamic baseline tracking, peak detection, and Inter-Beat Interval (IBI) analysis to confirm human biological liveness over 4 consecutive heartbeats.
  • Core 0 (Security & State Controller): Manages the vault authentication state machine, queries the DS1302 RTC for authorized time windows (08:00 - 18:00), monitors 3D seismic jerk from the MPU-6050, and triggers the heavy-duty magnetic lock solenoid relay.
