Project 1: FreeRTOS 6-DOF Inertial AHRS & Gimbal Stabilizer

Level 2 Sensor Fusion Architecture

This project implements a real-time Attitude and Heading Reference System (AHRS) on the dual-core ESP32-S3 (Xtensa LX7 @ 240 MHz). It fuses high-speed 6-DOF inertial rates from the GY-521 (MPU-6050) using the Mahony Filter to cancel gyroscope bias drift and estimate roll, pitch, and yaw quaternions at 100 Hz.

1. Multi-Core FreeRTOS Task Architecture

  • Core 1 (Priority 5 - Real-Time): Runs TaskSensorFusion at a deterministic 100 Hz (10ms) interval via vTaskDelayUntil. Samples MPU-6050 via 400 kHz Fast-Mode I2C, updates Mahony quaternions, reads Joystick setpoints, and drives high-resolution LEDC PWM gimbal outputs.
  • Core 0 (Priority 1 - Network): Handles the Wi-Fi 802.11 stack, SoftAP, and asynchronous JSON REST endpoints, completely isolating network latency from flight/stabilization control.
  • Thread-Safe Inter-Core Queue: Real-time attitude data is passed from Core 1 to Core 0 using FreeRTOS xQueueOverwrite with zero lock contention.

3. Mathematical Sensor Fusion: Mahony Filter

Gyroscopes suffer from slow drift over time, while accelerometers are corrupted by centrifugal and linear accelerations. The Mahony filter computes the cross product between the gravity vector estimated from quaternions $\hat{v} = (v_x, v_y, v_z)$ and the normalized measured gravity vector $a = (a_x, a_y, a_z)$:

$$\vec{e} = \vec{a} \times \hat{v}$$

This error vector is multiplied by proportional gain ($K_p$) and integral gain ($K_i$) and fed back into the gyroscope integration rates, providing smooth drift-free attitude tracking.
