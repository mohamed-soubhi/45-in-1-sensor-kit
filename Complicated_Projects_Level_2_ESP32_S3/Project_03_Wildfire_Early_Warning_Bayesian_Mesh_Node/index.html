Project 3: Environmental Micro-Climate & Wildfire Early-Warning Node

Level 2 Sensor Fusion: Multi-Spectral Bayesian Modeling

Forest fires propagate through complex thermodynamic feedback loops: Low atmospheric relative humidity + High solar radiation dry out forest understory litter → Ground fuel moisture drops → Heat + Sparks initiate combustion. This project integrates 5 physical domain sensors from the 45-in-1 kit into a Bayesian probabilistic inference engine on the dual-core ESP32-S3.

1. Multi-Core Architecture & Wireless Portal

  • Core 1 (Real-Time Fusion): Evaluates atmospheric Equilibrium Moisture Content (EMC), Fuel Vulnerability Index (FVI), and optical flame signatures every 100ms.
  • Core 0 (Autonomous Station Portal): Hosts an embedded Wi-Fi Access Point (ESP32S3-Wildfire-Sentinel) serving a live responsive web dashboard with JSON metrics stream.
  • Sprinkler Interlock: Directly commands a 5V relay to trigger autonomous perimeter misting valves when composite fire probability exceeds 75%.

3. Mathematical Core: Probabilistic Bayesian Inference

The probability of wildfire ignition is modeled as the joint complement of safe fuel state and absence of active combustion signatures:

$$P(\text{Wildfire}) = 1 - \big[(1 - 0.6 \cdot P_{\text{Fuel}}) \times (1 - P_{\text{Combustion}})\big]$$

Where $P_{\text{Fuel}}$ fuses temperature, humidity deficit, and soil dryness via calibrated sigmoid transfer functions.
